最終更新: 2026-10-29。これが唯一の正本。迷ったらこのファイルに従う。

## 0. 一言で

**「カワセミは、速い。」** 手描きステッカー風のキャラクターと、新幹線のスピード感を、
青1色＋橙1色のクリーム地で見せる。遊び心は演出で、落ち着きは余白と書体で出す。

- 方向: playful / toy-like（ステッカー・おもちゃの新幹線）× editorial（見出しは大きく、本文は静か）
- 記憶に残す1点: **開いた瞬間、カワセミが左下から右上へ羽ばたいて抜け、着地と同時に「？」が「！」に変わる**
- 対象読者: ハッカソンの審査員・スポンサー・他チーム・採用担当・後輩

## 2. 色（CSS 変数のみで使う。インラインの色値は禁止）

```css
:root {
  --blue:        #1E7FE6; /* 主役。カワセミの羽 */
  --blue-deep:   #0F4FA8; /* 主役の濃い側。ホバー・見出しの影 */
  --blue-pale:   #BFE0FF; /* 主役の薄い側。帯・下線 */
  --orange:      #F39A1E; /* 他1色。胸。差し色は「見出し語・主ボタン・『！』・年表の現在地」だけ */
  --orange-deep: #F2521B; /* 「！」の朱 */
  --cream:       #F4EFD6; /* 地。原画の背景色 */
  --cream-2:     #FBF8EA; /* 地の明るい側（交互の節で使う） */
  --navy:        #10264A; /* 輪郭線・暗い帯の地。3色目には数えない */
  --ink:         #1B2B45; /* 本文の文字 */
  --ink-soft:    #4A5A75; /* 補足の文字 */
}
```

- 面の色は **青・橙・クリーム** の3つだけ。白・灰・黒の面を主役にしない
- 濃紺の帯（Journey 節）は「夜の矢上を走る新幹線」のための地。節1つだけに使う
- 本文の文字は `--ink` on `--cream` でコントラスト比 4.5 以上を保つ。橙の上の文字は `--navy`

## 3. 書体（Google Fonts）

| 役割 | 書体 | 使いどころ |
|---|---|---|
| 和文見出し | **Dela Gothic One** | 各節の見出し、ヒーローの2行 |
| 本文 | **Zen Maru Gothic**（400 / 500 / 700） | 本文・キャプション・ボタン |
| 英字の飾り | **Unbounded**（600 / 800） | 節の英字ラベル（ABOUT / WORKS …）、背景に薄く重ねる「ALCEDO」、数字 |

- 見出しと本文のサイズ差は3倍以上（節の見出し `clamp(2.2rem, 5.2vw, 4.8rem)`、ヒーローの2行 `clamp(1.65rem, 3.9vw, 3.3rem)`＝1行目12文字が 62% の列に `nowrap` で収まる上限、本文 `1.0625rem`）
- 行間: 見出し 1.15、本文 1.9。字間: 見出し 0.02em、英字ラベル 0.18em

## 4. レイアウトの規則（remove-ai-look の規則を守る）

- **器（コンテンツ幅）は中央** に置く: `max-width: 1232px; margin-inline: auto; padding-inline: clamp(16px, 5vw, 48px)`
- 非対称は **器の中の配分** で作る（写真＋文字の節は 62:38。文字だけの節は本文 760px を器の左端に揃える）
- 見出しの左端は、どの節でも器の左端に揃える（中央揃えの見出しはヒーローと Contact だけ）
- **要素を角丸の枠で囲んで並べない。** 区切りは余白と `--navy` の細い罫線1本だけ
- 同じ形のカードを同じ大きさで等間隔に並べない。Works は2作品で大きさを変える、About の3つの柱は段違いに置く、Members の5人は高さをずらす
- 写真全面に暗幕をかけない。文字の後ろだけ暗くする
- 形の種類: 「斜めの切り口（新幹線の先頭の角度 ≒ 12°）」「くちばし形の矢印」「丸いドット（メンバーの色）」の3種類に限定し、理由がある場所だけで使う
- モバイル 320 / 375 / 414 / 768px で横スクロールが出ないこと。`grid` は `minmax(0, 1fr)`
- 節の境目は 12° の斜面（新幹線の先頭）で切る。画面全幅を 12° にすると高さが出すぎるので、水平区間の先に斜面を置く。Hero→About、Members→Journey、Journey→Contact の3か所だけ

## 6. 演出（JS。全部盛り。ただし `prefers-reduced-motion: reduce` では全演出を静止画に）

### 6-1. ヒーローの飛翔（最重要。`js/hero.js`）
1. 読み込み直後、画面全体に `--cream` のレイヤー。左下（`-12vw, 108vh`）から **生成画像の飛翔ポーズ `assets/char/flying.png`** が右上へ飛ぶ（自作 SVG のシルエットは画風が原画と合わず不採用）
   - 羽ばたき: 翼を下ろした2コマ目 `assets/char/flap.png` があれば 0.2s 周期で交互に表示。無ければ1コマに上下動（±2.5%）だけ
   - 画像はもともと右上（約 −32°）を向いているので、進行方向の角度に +32° を足して回転させ、着地では 0° に戻す
   - 軌道: `offset-path: path("M -12 108 C 20 95, 45 60, 62 38 S 85 20, 112 -8")`（vw/vh を % に換算して使う）、`offset-rotate: auto`、所要 2.2s、`cubic-bezier(.3,.0,.2,1)`
   - 速度線は画像に描き込まれているので、別に描かない
2. 1.5s 時点で、鳥はヒーロー右側の着地点（デスクトップ: 器の右 38%、モバイル: 見出しの下）へ向かってサイズを 0.6 倍に落としながら減速し、`assets/char/question.png` へ **クロスフェード**（SVG は不透明度 0、PNG は 0→1、0.35s）
3. 着地と同時にキャラが弾む（`scale(.82)→1.06→1`）。0.6s 後、PNG を `assets/char/exclaim.png` にクロスフェード。「？」「！」と放射線は生成画像に描き込まれているので、CSS では描かない（二重になる）
4. 「！」の切り替えと同時に、見出し2行目「いや、アルケド？」が下から 12px 持ち上がって出る（1行目は飛翔中に文字単位で出しておく）
5. 全体 3.2s 以内。`sessionStorage.alcedoSeen` があれば短縮版（飛翔 0.9s、ステップ3以降は同じ）
6. 飛翔中もページはスクロールできる。レイヤーは `pointer-events: none`

### 6-2. スクロール出現と新幹線
- 各節の見出し・本文・画像は `IntersectionObserver` で `is-in` を付け、`opacity` と `translateY(16px)` で出す（stagger 60ms）
- 斜めの境目3か所では、スクロール位置に応じて **新幹線の画像 `assets/char/train-side.png`**（原画の新幹線を codex で単体に描き起こした透過 PNG。白無地の車体、灰色の帯、濃紺の先頭窓、車輪、手書きの「Alcedo」、青と橙の速度線。自作 SVG は線の味が出ず不採用）が左から右へ境目に沿って横切る。進み具合は `scrollY` から計算（アニメーションではなくスクラブ）

### 6-3. Works ＝ 連結した車両
- 横並びの `scroll-snap` トラック。各作品は1両。1両目（東京RPG）は幅 `min(880px, 86vw)`、2両目（Astera）は `min(720px, 80vw)`。車両どうしは短い「連結器」（`--navy` の線）でつなぐ
- 車両の左端は 12° の斜め（先頭）。中は 62:38（画像 62 / 文字 38）。画像3枚は重ねてずらす（等間隔に並べない）
- 「詳しく見る」で1両が縦に展開し、数字のカウントアップ（§6-5）・技術・リンクが出る。展開中は他の車両が少し暗くなる
- 左右のボタンはくちばし形の矢印。キーボードの ← → でも動く

### 6-4. Journey ＝ 線路と新幹線
- 濃紺の帯の中に、横（モバイルは縦）の線路（`stroke-dasharray` の枕木付き）。駅ごとにドット（青）と年月・出来事
- スクロール位置に応じて新幹線が線路上を進み、通過した駅のドットが橙に変わって出来事の文字が出る。最後の「次の駅」はドットだけ点滅

### 6-5. 数字のカウントアップ
- `486 → 24`、`6`、`5`、`43`、`58`、`180` を、表示領域に入ったとき 0.9s で数える（`requestAnimationFrame`、easeOutCubic）。一度だけ

### 6-6. 見出しの文字出し＋背景の英字
- 各節の見出しは文字単位に `<span>` を切り、`is-in` で 30ms ずつ出す
- Hero と Members の背景に Unbounded の巨大な英字（ALCEDO / MEMBERS）を `position: absolute` で器からはみ出して重ねる。`overflow-x: clip` で横スクロールを出さない

### やらないこと
- カーソル追従の粒子、無限に動く背景、音
- 3色目の面、角丸の枠カード、仮画像の記号

## 8. 品質の確認（実装者がやること）

1. `python3 -m http.server 8787` を背景で立て、Playwright で 1440×900 と 390×844 のフルページ画像を `docs/screenshots/` に保存する（`desktop.png` `mobile.png`、飛翔が終わった 4s 後に撮る）
2. コンソールにエラー・警告が 0 件
3. 320 / 375 / 414 / 768 / 1024 / 1440 で `document.documentElement.scrollWidth <= innerWidth`
